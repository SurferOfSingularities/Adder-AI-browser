# Git Operations

## Commit Message Conventions

When making commits, follow the conventions established in this repository's git history:

- Format: `Commit N - <Short description of what was done>`
- Use a sequential commit number followed by a dash and a concise summary of the change.
- The description should be imperative mood and describe *what* the commit does (e.g. "Add multi-tab browsing", "Move UIState to viewmodel").
- Keep the subject line under 72 characters.
- Do not use conventional commit prefixes (feat:, fix:, chore:) unless the existing history uses them for that particular change.
